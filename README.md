# 👑 96K Men's Wear – E-Commerce Website

Instagram (50.5K Followers) Viral Clothing Brand साठी संपूर्ण ई-कॉमर्स वेब ॲप्लिकेशन.

---

## 🚀 मुख्य वैशिष्ट्ये (Key Features)

1. **Reels-Commerce ("As Seen On Reels")**:
   - इंस्टाग्राम रील व्हिडिओ सारखे व्हर्टिकल कार्ड्स (Paper Linen, Bootcut Jeans, KDK Special).
   - थेट "Shop Look" बटणाने ग्राहक तोच कपडा खरेदी करू शकतात.
2. **शून्य-पेमेंट गेटवे अडचण (Zero-Payment Gateway Hassle)**:
   - **WhatsApp Direct Order**: १-क्लिक मध्ये मराठी आणि इंग्रजीत आयटम, साईज, रंग, पत्ता आणि बिलासह मेसेज थेट दुकानदाराच्या व्हॉट्सॲपवर पाठवला जातो.
   - **Cash on Delivery (COD)**: पत्ता टाकून थेट ऑर्डर नोंदवली जाते.
   - **Scan & Pay (Direct UPI)**: फोनपे किंवा गुगल पे QR कोड थेट दाखवला जातो, ज्यामुळे थेट बँक खात्यात पैसे येतात (गेटवे फी शून्य!).
3. **मोबाईल-फर्स्ट डिझाईन**:
   - इंस्टाग्रामवरून येणाऱ्या ९०%+ मोबाईल युझर्ससाठी सुपरफास्ट व स्मूथ अनुभव.
   - साईज चार्ट (इंचामध्ये छाती व लांबीची माहिती) जेणेकरून एक्सचेंजची गरज पडत नाही.
   - पिनकोड डिलिव्हरी चेकर (महाराष्ट्र २-३ दिवस, भारतभर ३-५ दिवस).

## 🛠️ प्रोजेक्ट कसे चालवायचे (How to Run Locally)

```bash
# १. डिपेंडन्सी इन्स्टॉल करा
npm install

# २. डेव्हलपमेंट सर्व्हर सुरू करा
npm run dev
```

ब्राउझरमध्ये `http://localhost:3000` उघडा.
